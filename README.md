# User Management CRUD API

A simple User Management application that allows users to create and delete user records using React and Node.js.

## Technologies Used

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt

## Features

- Create a new user.
- Delete an existing user.
- Validate user input.
- Store user details in MongoDB.
- Hash passwords using bcrypt.
- Display success and error messages.
